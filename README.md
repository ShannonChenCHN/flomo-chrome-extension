# flomo 笔记清空 · Chrome 扩展

一个仅供个人使用的 Chrome 扩展（Manifest V3），通过**网页 UI 自动化**批量删除 [flomo](https://flomoapp.com/)（v.flomoapp.com）云端笔记。

> ⚠️ **危险操作工具**：删除会把笔记移入回收站。使用前请务必自行备份，并确认你理解后果。

## 功能

- **扫描笔记**：自动滚动笔记列表，按每张卡片头部链接中的 `memo_id` 去重统计（不会误算笔记正文里的内部引用链接）。
- **批量删除**：逐条触发卡片右上角「···」菜单 → 点击「删除」，全程走 flomo 网页原生 UI，**不调用任何内部/私有 API**。
- **暂停 / 继续 / 停止**：删除过程中可随时暂停或中止。
- **状态持久化**：扫描数与删除进度实时写入 `chrome.storage.local`。弹窗因失焦关闭后重新点击扩展图标，扫描结果、删除进度、暂停/停止按钮都会自动恢复（content script 仍在后台继续运行）。
- **安全确认**：开始删除前需手动输入 `DELETE ALL FLOMO NOTES`。

## 安装（加载未打包扩展）

1. 下载/克隆本仓库到本地。
2. 打开 Chrome，地址栏输入 `chrome://extensions`。
3. 打开右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本项目目录（包含 `manifest.json` 的文件夹）。
5. 修改代码后，需在扩展卡片上点击「刷新」按钮，并重新刷新 flomo 页面使 content script 生效。

## 使用步骤

1. 在浏览器中打开并登录 <https://v.flomoapp.com>。
2. 点击工具栏上的 flomo 扩展图标。
3. 点击「扫描笔记」，等待滚动扫描完成，确认笔记总数。
4. 确认你**已经完成备份**（重要数据建议先通过 flomo 官方导出功能备份）。
5. 在输入框中输入 `DELETE ALL FLOMO NOTES`，点击「开始删除」。
6. 删除过程中可「暂停 / 继续 / 停止」。即使弹窗关掉，后台仍会继续，重新打开弹窗可查看最新进度。
7. 全部删除完成后，如需永久清除，请**手动**前往 flomo 回收站清空。

## 工作原理

| 环节 | 实现方式 |
|---|---|
| 菜单显示 | 注入 CSS 强制 `.menu-trigger` 始终可见，绕过 hover 才显示的限制 |
| 定位笔记 | 遍历 `.memo` 卡片，从卡片头部 `a[href*="memo_id=..."]` 提取唯一 ID |
| 滚动容器 | `DIV.memos`，扫描时滚到底部触发懒加载；删除前先滚回顶部，删除中按屏向下滚动 |
| 执行删除 | 点击卡片 `.menu-trigger` → 在下拉菜单中找到「删除」项（`.menu-item.danger` 等多级兜底）并点击 |
| 结果校验 | 删除后检查该 `memo_id` 的卡片是否已从 DOM 消失 |

flomo 的卡片菜单点击「删除」后**直接移入回收站，没有二次确认弹窗**，因此扩展以较慢的固定间隔（默认 1.2 秒/条）逐条执行，降低误操作与页面压力。

## 隐私与安全

- 不收集、不上传任何数据；不读取 Cookie、Token 或笔记正文内容。
- 不包含远程脚本、`eval` 或动态代码执行。
- 不调用 flomo 内部接口，仅模拟用户在页面上的点击操作。
- 仅申请最小权限：`storage`（状态持久化）、`activeTab`，且 host 权限限定在 `https://v.flomoapp.com/*`。

## 项目结构

```
.
├── manifest.json   # MV3 配置：权限、content script、popup、图标
├── content.js      # 核心逻辑：CSS 注入、扫描、UI 删除、状态持久化
├── popup.html      # 弹窗界面结构
├── popup.css       # 弹窗样式
├── popup.js        # 弹窗逻辑：与 content.js 通信、状态恢复
├── flomo.webp      # flomo logo 原图
└── icons/          # 扩展图标 16 / 48 / 128（PNG）
```

## 已知限制

- 仅适配 flomo 网页版当前 DOM 结构；若 flomo 改版导致类名/结构变化，删除逻辑可能失效。
- 删除依赖页面渲染速度，网络较慢时可在 `content.js` 顶部的 `CONFIG` 中调大 `DELETE_INTERVAL` / `SCROLL_WAIT`。
- 扩展不会自动清空回收站，永久删除需手动操作。
